# iRacing Season Parser

Herramienta para analizar los PDF oficiales de iRacing y generar una estructura de datos reutilizable por iRTM.

## Objetivos

Fase 1
- Leer el PDF.
- Detectar las Series.
- Detectar las páginas.
- Exportar un JSON de inspección.

Fase 2
- Extraer el calendario.
- Detectar semanas.
- Detectar circuitos.
- Detectar fechas.

Fase 3
- Resolver Series con la base de datos.
- Resolver Circuitos con la base de datos.

Fase 4
- Importación automática en iRTM.
